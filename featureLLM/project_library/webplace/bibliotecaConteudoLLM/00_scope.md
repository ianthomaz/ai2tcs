# Webplace internal library

Indexed content for project `webplace` under the `featureLLM` tree in this repository.

Intended use:

- Conventions for calling the local LLM API from dev scripts (batch jobs, HIS, etc.).
- Short references for **structured extraction** and **address normalization** (field names, JSON shapes, retry hints).
- Optional pasted notes from runs (summaries, not secrets): keep tokens and credentials **out** of this folder.

After editing files here, run ingest for `webplace` so RAG stays current.
