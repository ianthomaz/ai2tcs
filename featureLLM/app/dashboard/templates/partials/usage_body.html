O que dá para medir daqui?

  • CPU e RAM em % vêm do psutil neste processo Python. No Docker, isso é a visão do container (limites de cgroup), não um mapa 1:1 da RAM total do Mac.
  • “Memória Ollama” usa o endpoint GET /api/ps do Ollama: modelos carregados e bytes que ele declara (VRAM em GPUs NVIDIA; em Apple Silicon o campo VRAM pode ser 0 mesmo com inferência a usar o chip — é limitação do relatório do Ollama, não um bug nosso).
  • Não existe na API HTTP pública do Ollama um número fiável de “% GPU Apple (Metal)” para desenhar um ponteiro como o Activity Monitor. Para isso seria preciso um agente no host (Mac) a exportar métricas, ou um servidor Linux com nvidia-smi.
  • O arco verde compara a soma da “pegada” dos modelos (VRAM ou residente, o que for maior) com a referência em GiB que configuraste — serve como indicador relativo, não como medida física certificada.
