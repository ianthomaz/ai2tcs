# Security

Report suspected vulnerabilities **privately** so we can fix them before public disclosure.

- Prefer **[GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)** for this repository (tab **Security** → **Report a vulnerability**), if enabled on the repo.
- If that is not available, open a **draft** issue with minimal reproduction details and ask the maintainers to treat it as security-sensitive, or e-mail **email@webplace.cc** (ITCS-Webplace) with subject line prefixed by `[security]`.

Please do **not** post exploit details or secrets in public issues or pull requests.
