# chinese_learning

Manifesto no ai2tcs (docs/27). Tutor de mandarim pelo `/edu` (chat, exercícios, progresso
do aluno). Protótipo: treina a conversa junto com o aiclaudia.

| | |
|---|---|
| Missão | tutor de chinês que conversa e acompanha o que o aluno erra |
| Canais | `chat` (interface do `/edu`) |
| Conhecimento | prompt do tutor (`app/edu/`) e progresso do aluno no banco; sem RAG por enquanto |
| Custo | só LLM local; limite por sessão |
| Regras da casa | herda as de qualquer canal (5 a 10) |

## Regras da casa que este projeto não segue

- 1 a 4 (conversa por mensagem): a aula é conversa (dono, 13/nov/2026).
